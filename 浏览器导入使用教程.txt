### 第 2 步：打开扩展管理页

1. 打开 Chrome。
2. 在地址栏输入：

```text
chrome://extensions/
```

3. 按回车。

Edge 用户输入：

```text
edge://extensions/
```

### 第 3 步：开启开发者模式

进入扩展管理页后：

1. 找到右上角 **开发者模式**。
2. 把开关打开。

### 第 4 步：加载扩展

1. 点击左上角 **加载已解压的扩展程序**。

3. 注意：要选择包含 `manifest.json` 的那个文件夹，不要选到外层压缩包目录。
4. 加载成功后会看到扩展名：**Titan007 足球预测助手**。

### 第 5 步：固定扩展图标

1. 点击 Chrome 工具栏右上角的拼图图标。

3. 点击旁边的图钉按钮。
4. 工具栏出现足球图标后，安装完成。

## 小白使用教程

### 1. 获取比赛 ID

比赛 ID 是球探网页地址中的数字。

例如分析页地址：

```text
https://zq.titan007.com/analysis/2906701cn.htm
```

其中比赛 ID 是：

```text
2906701
```

再例如胜平负页面地址：

```text
https://1x2.titan007.com/oddslist/2906701.htm
```

其中比赛 ID 也是：

```text
2906701
```

复制这个数字备用。

### 2. 打开扩展面板并输入插件密码

1. 点击浏览器右上角的足球图标 ⚽。
2. 会打开一个独立小窗口，标题为 **足球预测助手**。
3. 首次打开会出现使用验证界面。
4. 按界面提示关注公众号 **Ai应用研究社团**，发送关键词 **足球** 免费获取插件密码。
5. 在密码输入框中填写公众号回复的插件密码并点击 **解锁**。
6. 验证通过后会保存在本机浏览器，下次打开无需重复输入。
7. 这个窗口不会因为你点击网页其他地方而自动关闭。

### 3. 输入比赛 ID

在面板顶部输入框中填入比赛 ID，例如：

```text
2906701
```

旁边可以选择监控间隔：

- `1分钟`：高频，适合临近开赛观察变化。
- `2分钟`：默认推荐。
- `5分钟`：普通观察。
- `10分钟`：低频观察。

### 4. 单次采集数据

如果你只想马上抓一次数据：

1. 输入比赛 ID。
2. 点击 **⬇ 采集**。
3. 等待数秒。
4. 扩展会临时打开球探相关页面进行采集，完成后自动关闭。
5. 采集成功后可以切换到 **📊 盘口** 或 **📋 报告** 查看。

采集的数据包括：

- 赛前分析。
- 胜平负欧赔。
- 亚让盘口。
- 大小球盘口。
- 角球盘口。

### 5. 开始监控盘口变化

如果你想持续观察某场比赛：

1. 输入比赛 ID。
2. 选择间隔，例如 `2分钟`。
3. 点击 **▶ 监控**。
4. 扩展会按间隔自动采集。
5. 如果胜平负、亚让或大小球发生变化，会弹出桌面通知。

通知示例：

```text
胜平负: 主/平/客 1.85/3.40/4.20→1.80/3.50/4.30
亚让: 半球→半/一
大小球: 2.5→2.75
```

### 6. 查看盘口数据

切换到 **📊 盘口** 标签，可以看到：

- 胜平负盘口（欧赔）：初赔、即时赔率、均赔、隐含概率、主要公司赔率。
- 亚让盘口：主要公司初盘、即时盘和水位。
- 大小球盘口：进球线和大小球水位。
- 角球盘口：角球线和水位。
- 分析数据：球队基本信息、战绩、盘路走势等。

### 7. 运行本地预测

不配置 AI 也可以用本地预测：

1. 先点击 **⬇ 采集** 获取数据。
2. 切换到 **🤖 预测** 标签。
3. 点击 **🤖 运行本地预测**。
4. 查看本地算法给出的方向、信号和信心度。

本地预测只是一套内置规则，适合快速参考，不代表真实赛果。

### 8. 使用 AI 预测

如果你已配置 AI：

1. 先点击 **⬇ 采集** 获取数据。
2. 切换到 **✨ AI** 标签。
3. 点击 **✨ 开始AI预测分析**。
4. AI 会读取当前比赛数据并生成分析。
5. 你可以继续在输入框追问。

可以这样问：

```text
重点分析胜平负欧赔变化
```

```text
这场亚让盘是否有诱盘迹象？
```

```text
结合大小球和角球，给一个保守方案
```

```text
把这场比赛按风险分级总结一下
```

### 9. 今日赛事、勾选采集和 AI 批量分析

如果你想一次处理今日多场比赛：

1. 切换到 **📅 今日赛事** 标签。
2. 点击 **📅 采集今日比赛**，等待列表加载。
3. 根据联赛级别、球队、时间和价值评分勾选你想分析的比赛。
4. 点击 **📊 采集选中**，只采集勾选比赛；过程中可点击 **⏹ 停止**。
5. 已采集完成后点击 **✨ AI批量分析**。
6. AI 会按单场逐一分析，不会把多场比赛混成一段笼统结论。

> 提示：AI 批量分析只会分析“已勾选 + 已采集盘口数据”的比赛。没有采集数据的比赛需要先执行选中采集。

### 10. 战绩记录、赛后验证和删除

切换到 **📈 战绩** 标签，可以管理 AI 自动同步的投注建议记录：

1. AI 分析结果中出现 **高价值** 或 **中高价值** 的结构化建议时，会自动写入战绩。
2. 每条记录包含记录 ID、比赛、盘口类型、选项、赔率、价值等级、比分和结果。
3. 赛后点击 **验**，扩展会尝试读取比分并判断结果。
4. 也可以手动填写比分、选择结果后点击 **存**。
5. 不需要的记录可点击 **删**，也可以按日期删除当日记录。

### 11. 生成和复制报告

1. 切换到 **📋 报告** 标签。
2. 点击生成报告按钮，或采集后查看自动生成内容。
3. 报告是 Markdown 格式。
4. 可以复制后粘贴到 ChatGPT、Claude、DeepSeek 或其他 AI 工具中继续分析。

报告通常包含：

- 比赛基础信息。
- 双方战绩和近期表现。
- 联赛盘路走势。
- 伤停与简报。
- 胜平负欧赔。
- 亚让盘口。
- 大小球盘口。
- 角球盘口。
- AI 分析提示词。

### 12. 查看历史记录

切换到 **🕐 记录** 标签，可以查看历史预测记录，用于赛后复盘。

## AI 设置教程

点击面板右上角 **⚙ 设置**，进入设置页。

### 方案 A：OpenAI

1. AI 提供商选择 **OpenAI**。
2. 填入 API Key，例如 `sk-...`。
3. 模型名称可以填：

```text
gpt-4o
```

4. 点击 **💾 保存设置**。

### 方案 B：Claude

1. AI 提供商选择 **Claude**。
2. 填入 Anthropic API Key。
3. 模型名称按你的账号可用模型填写。
4. 点击 **💾 保存设置**。

### 方案 C：DeepSeek / 其他 OpenAI 兼容接口

1. AI 提供商选择 **自定义**。
2. 填写 API Key。
3. 填写模型名称，例如：

```text
deepseek-chat
```

4. 自定义 API 地址填写兼容 OpenAI 的接口地址，例如：

```text
https://api.deepseek.com/v1/chat/completions
```

5. 点击 **💾 保存设置**。

### 方案 D：本地 Ollama

如果你本机已安装 Ollama 并启动服务：

1. AI 提供商选择 **自定义**。
2. API Key 可以填任意占位内容，例如：

```text
ollama
```

3. 模型名称填写本地模型，例如：

```text
qwen2.5:7b
```

4. 自定义 API 地址填写：

```text
http://localhost:11434/v1/chat/completions
```

5. 点击 **💾 保存设置**。

> 提示：足球盘口分析需要较强推理能力，模型越强，报告解读通常越稳定。
