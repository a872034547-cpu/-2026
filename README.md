# ⚽ Titan007 足球预测助手

> 实时监控球探网（titan007.com）盘口数据，自动生成分析报告，支持 AI 对话预测 + 本地算法双引擎

---

## 🚀 功能特性

| 功能 | 说明 |
|------|------|
| 📡 实时监控 | 定时（1/2/5/10分钟）采集赛前分析、亚让盘、大小球、角球 |
| 📊 盘口数据 | 展示初盘→即时盘变化，高水/低水标注，多公司对比 |
| 🔔 变动通知 | 盘口发生变化时推送桌面通知 |
| 📋 报告生成 | 自动整理 Markdown 格式报告，可直接复制发给 AI |
| 💬 AI 对话 | 支持多轮对话，可持续追问，AI保留上下文 |
| 🤖 本地预测 | 内置盘口分析算法，无需 API Key |
| 🎯 滚球预测 | 比赛进行中实时预测角球/进球走势 |
| 📝 预测记录 | 自动保存所有预测，支持赛后复盘 |
| 🔊 提示音 | 高信心推荐时自动播放提示音 |
| 🪟 固定窗口 | 独立浮窗不会自动消失，可与网页同时查看 |

---

## 📦 安装方法

1. 下载或克隆本仓库
2. 打开 Chrome，进入 `chrome://extensions/`
3. 右上角开启 **开发者模式**
4. 点击 **加载已解压的扩展程序**，选择 `titan007-predictor` 文件夹
5. 工具栏出现足球图标即安装成功

---

## 🎮 使用方法

### 第一步：打开面板

点击 Chrome 工具栏中的足球图标 ⚽，打开**固定窗口**（不会自动消失）

### 第二步：输入比赛ID

在顶部输入框填写球探网比赛 ID（从分析页 URL 中获取）：

```
https://zq.titan007.com/analysis/12345678.html
                                  ↑ 这是比赛ID: 12345678
```

### 第三步：采集数据

- 点击 **📡 监控** → 开始定时采集（推荐比赛前30分钟开始）
- 或点击 **🔄 立即采集** 单次获取

### 第四步：查看预测

**AI 预测（💬 对话模式）：**
1. 切换到 **AI** 标签
2. 点击 **✨ 开始AI预测分析** → AI 自动获取数据并给出完整预测
3. 在底部输入框继续追问（Enter发送，Shift+Enter换行）：
   - "重点分析一下亚盘走势"
   - "这场比分预测多少"
   - "半场角球建议怎么投"
4. 🗑️ 按钮清空对话重新开始

**本地预测（🤖）：**
- 切换到 **预测** 标签 → 点击 **运行本地预测**
- 显示亚盘、大小球、角球、综合信心度
- 比赛中实时更新滚球预测

### 第五步：查看数据和报告

- **盘口** 标签：查看所有公司盘口数据
- **报告** 标签：查看/复制 Markdown 格式完整报告
- **记录** 标签：查看历史预测，填写赛后结果复盘

## ⚙️ AI 配置

点击右上角 ⚙ 进入设置：

| 提供商 | 说明 |
|--------|------|
| 自定义接口（默认） | 支持 DeepSeek、Ollama 等 OpenAI 兼容接口 |
| OpenAI | 需要 GPT-4o API Key |
| Claude | 需要 Anthropic API Key |

> 自定义接口只需填写域名，会自动补全 `/v1/chat/completions` 路径

## 📊 数据来源

| 数据类型 | 来源 URL |
|---------|---------|
| 赛前分析、统计、简报 | `zq.titan007.com/analysis/{id}.html` |
| 亚让盘口 | `zq.titan007.com/analysis/asiaodds_{id}.html` |
| 大小球盘口 | `zq.titan007.com/analysis/overodds_{id}.html` |
| 角球盘口 | `vip.titan007.com/corner/{id}.html` |

## 🛠️ 项目结构

```
titan007-predictor/
├── manifest.json          # Chrome MV3 扩展配置
├── background.js          # Service Worker（采集、监控、AI调用）
├── popup.html             # 主界面 HTML
├── popup.js               # 主界面逻辑（6个标签页）
├── options.html           # 设置页面
├── options.js             # 设置页面逻辑
├── icons/                 # 扩展图标
└── js/
    ├── ai-client.js       # AI接口（OpenAI/Claude/自定义+多轮对话）
    ├── predictor.js       # 本地预测算法 + 预测记录
    ├── report.js          # Markdown报告生成
    ├── collector.js       # 数据采集辅助
    └── content-extractor.js  # 页面内容提取
```

- 本工具仅供学习研究，请遵守相关法律法规
