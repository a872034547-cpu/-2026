# ⚽ Titan007 足球预测助手

基于 Chrome MV3 的球探网盘口采集、AI 分析与官方战绩同步工具。

> ⚠️ 仅供学习与数据整理研究，不构成任何投注建议。

---

## 安装

1. 下载源码，解压得到 `titan007-predictor` 文件夹。
2. 打开 Chrome → `chrome://extensions/` → 开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择 `titan007-predictor` 文件夹。
4. 工具栏出现 ⚽ 图标即安装成功。

---

## 快速开始

### 第一次使用

1. 点击 ⚽ 图标打开面板。
2. 按提示关注公众号「**Ai应用研究社团**」，发送关键词「**足球**」获取插件密码。
3. 输入密码解锁，之后不需要重复输入。

### 采集单场比赛

1. 在球探网找到比赛，URL 中的数字就是比赛 ID。
   例如 `zq.titan007.com/analysis/2906701cn.htm` → ID 为 `2906701`
2. 在面板顶部输入 ID，点「**⬇ 采集**」。
3. 约 10 秒后，盘口数据自动填充到「**📊 盘口**」Tab。

### AI 分析（如果没有在设置里配置AI，可以复制报告里的文档发送给网页对话AI，一样可以进行分析）

1. 采集完成后切换到「**✨ AI**」Tab。
2. 点「**✨ 开始AI预测分析**」，AI 读取盘口数据生成分析。
3. 可继续追问，例如：「重点分析亚盘水位变化」「这场有没有诱盘迹象」。

### 今日批量分析

1. 切到「**📅 今日赛事**」Tab → 点「**📅 采集今日比赛**」。
2. 勾选感兴趣的比赛 → 点「**📊 采集选中**」。
3. 采集完成后点「**✨ AI批量分析**」，每场单独生成分析。

## AI 设置

打开 **⚙ 设置** → 选择 AI 提供商：

| 提供商 | API Key 来源 | 模型示例 |
|---|---|---|
| OpenAI | platform.openai.com | `gpt-4o` |
| Claude | console.anthropic.com | `claude-3-5-sonnet-20241022` |
| 自定义（DeepSeek/Ollama等） | 自建或第三方 | `deepseek-chat` |

自定义接口地址填写 OpenAI 兼容格式，例如：
- DeepSeek：`https://api.deepseek.com/v1/chat/completions`
- 本地 Ollama：`http://localhost:11434/v1/chat/completions`

## 如何读懂预测结果

### 本地量化预测（📊 盘口 → 本地预测）

| 字段 | 说明 |
|---|---|
| 方向 | 主胜 / 平局 / 客胜，模型当前偏向 |
| 信心度 | 0-100，≥65 较可信，<45 建议观望 |
| 推荐 | 强烈推荐 / 推荐 / 谨慎 / 不推荐 |
| 信号 | 驱动预测的具体依据，例如「亚盘主水大幅下降」 |

### AI 分析结果（✨ AI Tab）

AI 会给出结构化建议，标记了以下价值等级：

| 标记 | 含义 |
|---|---|
| 🔥 **高价值** | 模型认为赔率存在明显优势，自动记入战绩 |
| ⭐ **中高价值** | 有一定优势但不确定性较高，也会记入战绩 |
| ℹ️ 中性/参考 | 仅供参考，不记入战绩 |

> **重要**：高价值不等于必中，AI 也会犯错。结果只代表模型在当前数据下的判断。

### 盘口关键信号解读

| 信号 | 参考含义 |
|---|---|
| 亚盘主水下降 + 盘口升高 | 资金倾向客队，主队被看低 |
| 欧赔主胜大幅升高 | 市场对主队信心下降 |
| 大球水位下降（大球变便宜）| 预期进球偏多 |
| 初盘与终盘盘口差异大 | 变盘明显，需谨慎分析方向 |

## 战绩（📈 战绩 Tab）

- AI 分析中出现高/中高价值建议时自动记入战绩。
- 赛后点「**验**」自动读取比分并判断是否命中。
- 也可手动填比分 + 选结果后点「**存**」。
- 战绩支持云同步（见下方官方战绩说明）。

### 战绩来源切换

| 模式 | 说明 |
|---|---|
| ☁️ 官方战绩 | 从服务器拉取管理员发布的官方高价值推荐（只读） |
| 📱 我的私有记录 | 本地保存的你自己 AI 分析产生的高/中高价值建议 |

> 普通用户 AI 预测的战绩不会污染官方战绩，存在「我的私有记录」中单独管理。

### 战绩公开展示页

如果服务端已部署，可通过 `records.html` 页面（放在 `football-api/` 目录下）浏览器直接打开，展示官方战绩的科技感数据看板：

- 命中率圆环 + 统计卡片（命中/未中/半赢/半输/待验证）
- 按日期、结果、价值等级三重过滤
- 手机自适应，右上角展示公众号二维码

## 官方战绩公开展示（records.html）

> 适合向用户展示历史战绩数据，无需登录，直接访问。

部署到虚拟主机后，将以下文件上传到同一目录：

```
api.php / config.php / record.php / match.php / stats.php / maintenance.php / .htaccess
records.html   ← 战绩展示网页
gzh.jpg        ← 公众号二维码图片（可替换为自己的）
```

打开 `https://your-domain.com/records.html` 即自动加载展示官方战绩。

## 官方战绩云同步（可选）

> 适合把插件分发给多人、统一推送官方预测记录的作者。不配置此功能不影响其他功能。

### 普通用户

1. 打开 **⚙ 设置** → 公共 API 地址填：`http://cdu.cc.cd/football-api/api.php`
2. 启用公共数据同步，管理员密钥**留空**。
3. 保存后战绩页自动显示官方战绩（只读）。

### 管理员（作者本人）

1. 公共 API 地址同上，管理员密钥填私钥。
2. 保存后：
   - 采集比赛数据会自动上传到服务器。
   - AI 战绩自动发布为官方记录。
   - 面板出现 **☁️ 同步** 按钮，点击可一次性上传所有本地战绩和比赛数据。
