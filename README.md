# ⚽ Titan007 足球预测助手

> 一个基于 Chrome Manifest V3 的球探网数据采集、盘口监控、Markdown 报告与 AI 足球分析辅助工具。

本扩展会在浏览器中打开球探 / Titan007 相关页面，自动采集赛前分析、胜平负欧赔、亚让盘、大小球和角球盘口数据，并在扩展面板中展示、监控变化、生成报告。适合需要把球探数据整理成结构化报告、再交给 AI 或本地算法辅助分析的用户。

> ⚠️ 重要声明：本项目仅用于学习、研究、数据整理和技术交流。任何预测结果都不构成投注建议，也不保证准确率。请遵守所在地法律法规，理性使用。

## 最近更新

- 🪟 **界面布局优化**：独立面板窗口宽度与页面宽度对齐，顶部按钮、标签栏、今日赛事按钮和战绩操作按钮改为紧凑布局，减少横向溢出。
- 📅 **今日赛事采集**：支持采集今日比赛列表，按联赛级别和价值评分筛选、勾选后选择性采集。
- ✨ **逐场 AI 批量分析**：批量分析只处理已勾选且已采集数据的比赛，每场单独生成详细分析。

- 🧠 **2.0 深度预测**：在保留原始数据给 AI 的基础上，增加本地量化结果和联网情报作为参考，辅助 AI 综合裁决。
- 📊 **富统计采集增强**：强化 analysis 页面入球分布、半全场、单双、进球时间、本赛季统计对比等富统计数据提取。

- 想把球探网多页面数据自动整理成一份报告的人。

## 准备工作

### 你需要什么

1. 一台 Windows / macOS / Linux 电脑。
2. Chrome 浏览器，或基于 Chromium 的浏览器，例如 Edge。
3. 本项目源码文件夹：`titan007-predictor`。
4. 可正常访问球探 / Titan007 网站的网络环境。
5. 可选：AI API Key，例如 OpenAI、Claude、DeepSeek 或本地 Ollama。

### 不需要什么

- 不需要安装 Node.js 才能使用扩展。
- 不需要命令行基础。
- 不配置 AI 也可以使用“采集数据”“生成报告”“本地预测”。

## 小白安装教程

下面按 Chrome 浏览器说明，Edge 操作类似。

### 第 1 步：下载项目

如果你从 GitHub 下载：

1. 打开仓库页面。
2. 点击绿色按钮 **Code**。
3. 点击 **Download ZIP**。
4. 下载完成后右键解压。
5. 找到解压后的 `titan007-predictor` 文件夹。

如果你已经有源码文件夹，只要确认里面能看到这些文件即可：

```text
titan007-predictor/
├── manifest.json
├── background.js
├── popup.html
├── popup.js
├── options.html
├── options.js
├── icons/
└── js/
```

### 第 2 步：打开扩展管理页

1. 打开 Chrome。
2. 在地址栏输入：

```text
chrome://extensions/
```

3. 按回车。

Edge 用户输入：

```text
edge://extensions/
```

### 第 3 步：开启开发者模式

进入扩展管理页后：

1. 找到右上角 **开发者模式**。
2. 把开关打开。

### 第 4 步：加载扩展

1. 点击左上角 **加载已解压的扩展程序**。
2. 选择 `titan007-predictor` 文件夹。
3. 注意：要选择包含 `manifest.json` 的那个文件夹，不要选到外层压缩包目录。
4. 加载成功后会看到扩展名：**Titan007 足球预测助手**。

### 第 5 步：固定扩展图标

1. 点击 Chrome 工具栏右上角的拼图图标。
2. 找到 **Titan007 足球预测助手**。
3. 点击旁边的图钉按钮。
4. 工具栏出现足球图标后，安装完成。

## 小白使用教程

### 1. 获取比赛 ID

比赛 ID 是球探网页地址中的数字。

例如分析页地址：

```text
https://zq.titan007.com/analysis/2906701cn.htm
```

其中比赛 ID 是：

```text
2906701
```

再例如胜平负页面地址：

```text
https://1x2.titan007.com/oddslist/2906701.htm
```

其中比赛 ID 也是：

```text
2906701
```

复制这个数字备用。

### 2. 打开扩展面板

1. 点击浏览器右上角的足球图标 ⚽。
2. 会打开一个独立小窗口，标题为 **足球预测助手**。
3. 这个窗口不会因为你点击网页其他地方而自动关闭。

### 3. 输入比赛 ID

在面板顶部输入框中填入比赛 ID，例如：

```text
2906701
```

旁边可以选择监控间隔：

- `1分钟`：高频，适合临近开赛观察变化。
- `2分钟`：默认推荐。
- `5分钟`：普通观察。
- `10分钟`：低频观察。

### 4. 单次采集数据

如果你只想马上抓一次数据：

1. 输入比赛 ID。
2. 点击 **⬇ 采集**。
3. 等待数秒。
4. 扩展会临时打开球探相关页面进行采集，完成后自动关闭。
5. 采集成功后可以切换到 **📊 盘口** 或 **📋 报告** 查看。

采集的数据包括：

- 赛前分析。
- 胜平负欧赔。
- 亚让盘口。
- 大小球盘口。
- 角球盘口。

### 5. 开始监控盘口变化

如果你想持续观察某场比赛：

1. 输入比赛 ID。
2. 选择间隔，例如 `2分钟`。
3. 点击 **▶ 监控**。
4. 扩展会按间隔自动采集。
5. 如果胜平负、亚让或大小球发生变化，会弹出桌面通知。

通知示例：

```text
胜平负: 主/平/客 1.85/3.40/4.20→1.80/3.50/4.30
亚让: 半球→半/一
大小球: 2.5→2.75
```

### 6. 查看盘口数据

切换到 **📊 盘口** 标签，可以看到：

- 胜平负盘口（欧赔）：初赔、即时赔率、均赔、隐含概率、主要公司赔率。
- 亚让盘口：主要公司初盘、即时盘和水位。
- 大小球盘口：进球线和大小球水位。
- 角球盘口：角球线和水位。
- 分析数据：球队基本信息、战绩、盘路走势等。

### 7. 运行本地预测

不配置 AI 也可以用本地预测：

1. 先点击 **⬇ 采集** 获取数据。
2. 切换到 **🤖 预测** 标签。
3. 点击 **🤖 运行本地预测**。
4. 查看本地算法给出的方向、信号和信心度。

本地预测只是一套内置规则，适合快速参考，不代表真实赛果。

### 8. 使用 AI 预测

如果你已配置 AI：

1. 先点击 **⬇ 采集** 获取数据。
2. 切换到 **✨ AI** 标签。
3. 点击 **✨ 开始AI预测分析**。
4. AI 会读取当前比赛数据并生成分析。
5. 你可以继续在输入框追问。

可以这样问：

```text
重点分析胜平负欧赔变化
```

```text
这场亚让盘是否有诱盘迹象？
```

```text
结合大小球和角球，给一个保守方案
```

```text
把这场比赛按风险分级总结一下
```

### 9. 今日赛事、勾选采集和 AI 批量分析

如果你想一次处理今日多场比赛：

1. 切换到 **📅 今日赛事** 标签。
2. 点击 **📅 采集今日比赛**，等待列表加载。
3. 根据联赛级别、球队、时间和价值评分勾选你想分析的比赛。
4. 点击 **📊 采集选中**，只采集勾选比赛；过程中可点击 **⏹ 停止**。
5. 已采集完成后点击 **✨ AI批量分析**。
6. AI 会按单场逐一分析，不会把多场比赛混成一段笼统结论。

> 提示：AI 批量分析只会分析“已勾选 + 已采集盘口数据”的比赛。没有采集数据的比赛需要先执行选中采集。

### 10. 战绩记录、赛后验证和删除

切换到 **📈 战绩** 标签，可以管理 AI 自动同步的投注建议记录：

1. AI 分析结果中出现 **高价值** 或 **中高价值** 的结构化建议时，会自动写入战绩。
2. 每条记录包含记录 ID、比赛、盘口类型、选项、赔率、价值等级、比分和结果。
3. 赛后点击 **验**，扩展会尝试读取比分并判断结果。
4. 也可以手动填写比分、选择结果后点击 **存**。
5. 不需要的记录可点击 **删**，也可以按日期删除当日记录。

### 11. 生成和复制报告

1. 切换到 **📋 报告** 标签。
2. 点击生成报告按钮，或采集后查看自动生成内容。
3. 报告是 Markdown 格式。
4. 可以复制后粘贴到 ChatGPT、Claude、DeepSeek 或其他 AI 工具中继续分析。

报告通常包含：

- 比赛基础信息。
- 双方战绩和近期表现。
- 联赛盘路走势。
- 伤停与简报。
- 胜平负欧赔。
- 亚让盘口。
- 大小球盘口。
- 角球盘口。
- AI 分析提示词。

### 12. 查看历史记录

切换到 **🕐 记录** 标签，可以查看历史预测记录，用于赛后复盘。

## AI 设置教程

点击面板右上角 **⚙ 设置**，进入设置页。

### 方案 A：OpenAI

1. AI 提供商选择 **OpenAI**。
2. 填入 API Key，例如 `sk-...`。
3. 模型名称可以填：

```text
gpt-4o
```

4. 点击 **💾 保存设置**。

### 方案 B：Claude

1. AI 提供商选择 **Claude**。
2. 填入 Anthropic API Key。
3. 模型名称按你的账号可用模型填写。
4. 点击 **💾 保存设置**。

### 方案 C：DeepSeek / 其他 OpenAI 兼容接口

1. AI 提供商选择 **自定义**。
2. 填写 API Key。
3. 填写模型名称，例如：

```text
deepseek-chat
```

4. 自定义 API 地址填写兼容 OpenAI 的接口地址，例如：

```text
https://api.deepseek.com/v1/chat/completions
```

5. 点击 **💾 保存设置**。

### 方案 D：本地 Ollama

如果你本机已安装 Ollama 并启动服务：

1. AI 提供商选择 **自定义**。
2. API Key 可以填任意占位内容，例如：

```text
ollama
```

3. 模型名称填写本地模型，例如：

```text
qwen2.5:7b
```

4. 自定义 API 地址填写：

```text
http://localhost:11434/v1/chat/completions
```

5. 点击 **💾 保存设置**。

> 提示：足球盘口分析需要较强推理能力，模型越强，报告解读通常越稳定。

## 常见问题

### 1. 加载扩展时报错怎么办？

先确认你选择的是包含 `manifest.json` 的 `titan007-predictor` 文件夹。

如果修改过源码，可以在项目目录执行语法检查：

```cmd
for %f in (*.js js\*.js) do @node --check "%f"
```

如果你不会命令行，最简单的方法是重新下载一份干净源码再加载。

### 2. 点击采集后为什么会弹出几个网页？

这是正常现象。扩展需要打开球探页面，让浏览器加载真实 DOM，再注入脚本读取数据。采集完成后会自动关闭这些临时标签页。

### 3. 为什么第一次采集比较慢？

球探页面有动态脚本和表格加载，扩展会等待页面内容出现。第一次通常需要 6 到 10 秒。

### 4. 采集不到数据怎么办？

可以按顺序检查：

1. 比赛 ID 是否正确。
2. 浏览器是否能直接打开球探对应页面。
3. 页面是否需要刷新或存在访问限制。
4. Chrome 扩展管理页中是否有错误提示。
5. 是否刚安装扩展但没有刷新相关页面。

### 5. AI 没有回复怎么办？

检查：

1. API Key 是否填写正确。
2. 模型名称是否可用。
3. 自定义 API 地址是否完整，通常应以 `/v1/chat/completions` 结尾。
4. 网络是否能访问对应 AI 服务。
5. 是否已经先采集了比赛数据。

### 6. 不配置 AI 可以用吗？

可以。你仍然可以使用：

- 数据采集。
- 盘口查看。
- 监控通知。
- Markdown 报告。
- 本地预测。

只有 **✨ AI** 对话功能需要配置 AI。

### 7. 监控通知没有弹出来怎么办？

检查：

1. 浏览器是否允许该扩展发送通知。
2. 系统通知是否开启。
3. 盘口是否真的发生了变化。
4. 是否已经点击 **▶ 监控**，而不是只点击 **⬇ 采集**。

### 8. 胜平负数据在哪里看？

采集完成后打开 **📊 盘口** 标签，找到 **胜平负盘口（欧赔）** 区块。报告中也会出现 **胜平负盘口（欧赔 / 1x2）** 章节。

### 9. 按钮或战绩表格看不全怎么办？

新版已将独立面板默认宽度调整到适配内容，并对按钮、标签栏、今日赛事列表和战绩表格做了紧凑防溢出布局。如果更新后仍看到旧窗口大小，请：

1. 打开 `chrome://extensions/`。
2. 找到 **Titan007 足球预测助手**。
3. 点击刷新按钮重新加载扩展。
4. 关闭旧的扩展面板窗口，再重新点击扩展图标打开。

## 开发者说明

### 当前技术栈

- Chrome Extension Manifest V3。
- Background Service Worker，使用 ES module。
- `chrome.tabs` + `chrome.scripting.executeScript` 标签页注入采集。
- `chrome.storage.local` 保存比赛数据和监控任务。
- `chrome.storage.sync` 保存 AI 设置。
- 原生 HTML / CSS / JavaScript，无前端框架。

### 主要数据结构

采集后每场比赛大致保存为：

```js
{
  matchId: '2906701',
  fetchTime: '2026-05-31T00:00:00.000Z',
  analysis: {},
  winDrawWin: {},
  asian: {},
  overunder: {},
  corner: {},
  richStats: {},
  quant: {}
}
```

其中 `winDrawWin` 用于胜平负 / 欧赔数据，避免和 `asian`、`overunder`、`corner` 混在一起。
